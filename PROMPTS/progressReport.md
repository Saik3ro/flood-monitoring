# Goal: Create a Progress Report for the FloodSight Website Dashboard

## Task:
* Provide a comprehensive progress report in the making of the FloodSight Website Dashboard, all the way from its first set of creation to the current status of today
* Be in-depth about the report, give notes about the features, new and old sections, backend connections, frontend redesigns, etc
* Read and explore the entire database and codebase for further understanding of the project
* Run the project using commands in order to explore the dashboard and take screenshots
* Ask questions for further clarifications before creating the progress report

## Prerequisites
* Read LOGS.md, this is where all the changes and features made are documented along the project's creation
* Read SPEC.md, this is where the identity of the project is located
* Read RULES.md, this is the coding standard and rules to be followed in the codebase

## Acceptance Criteria
* The output must be located in the project root folder with the name titled "Progress Report.docs"
* The document file must follow these specific format:
1. A4 Size Bondpaper
2. Normal Margins
3. Lexend Font
4. Consists of Subsections to differentiate the different features, codes and sections or pages added throughtout the creation of the project
5. Multiple Pages
6. Screenshots of the different pages of the FloodSight Website Dashboard, you can run the project locally for this
